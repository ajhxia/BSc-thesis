# Tailscale and NAT Traversal

**Bachelor's Thesis in Computer Science**  
Sapienza University of Rome — Department of Computer Science

## Overview

This repository contains the LaTeX source code for my bachelor's thesis, focused on **Tailscale and NAT Traversal**, with particular attention to peer-to-peer connectivity across different NAT environments.

The thesis explores NAT behavior, traversal techniques such as STUN, TURN and UDP hole punching, and the role of WireGuard in secure communication.

The experimental analysis focuses on evaluating how Tailscale establishes and maintains peer-to-peer connections under different network conditions.

Compile `Thesis.tex` using a compatible LaTeX distribution.
